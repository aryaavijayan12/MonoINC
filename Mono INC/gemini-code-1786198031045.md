# Trustopoly - Strategic Realtime Board Game

Trustopoly is a web-based, multiplayer board game centered on corporate trusts, fractional property holdings, custom loans, and interactive markets.

## Setup Instructions

1. Upload all repository files to GitHub.
2. Enable GitHub Pages under **Settings -> Pages -> Source (main branch)**.
3. Edit `firebase-config.js` with your Firebase Web project API credentials to enable cross-device realtime synchronization.
